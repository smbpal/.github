## SMBPal

Create and connect to SMB file shares, with one consistent interface across macOS, Windows,
Linux/Raspberry Pi, Android and iOS.

Built first for the **Raspberry Pi Desktop** user, for whom Pi OS ships no SMB GUI at all.

Deliberately small. A file-sharing utility asks for admin rights and stores credentials, so it
should look like it does one thing competently — not like a 200 MB installer.
