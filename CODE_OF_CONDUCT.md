# Code of conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, by reference rather than by copying it here.

The short version: be civil, assume good faith, and keep criticism aimed at the work.

Reporting is the awkward part of a one person project and it is better to say so than to invent a
process. There is one maintainer and no separate address, so a conduct concern goes through the
same private channel as a security report, on
[smbpal-desktop](https://github.com/smbpal/smbpal-desktop/security/advisories/new). That is an
odd route and it is the only private one that exists today. It will be replaced when there is
somebody else to replace it with.
